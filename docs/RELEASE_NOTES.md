# AMANZINE — Release Notes (Need OS sprint)

لقطة لأهمّ ما تغيّر في هذه المرحلة (من الأحدث للأقدم). التفاصيل الكاملة في `git log`.

## الهويّة والتجربة
- **هويّة Need OS**: index.html · package.json · manifest · Landing badge/SEO/tagline
  (٥ لغات) → «نظام تشغيل للحاجة». أُرشِفت ١٤ وثيقة تجارة قديمة في `docs/archive/`.
- **Landing جديدة**: ثيم زمرّد/ذهب + Hero «شنو محتاج اليوم؟» بعرض حيّ للعقل.
- **الجولة (TourGuide) اختياريّة**: لا تُعتِّم الصفحة دون طلب (لافتة تُدعى بنقرة).

## العقل والمعرفة
- **دليل المالك** (مركز القيادة › تبويب «المالك»): يشرح التطبيق نفسه بلغة المالك —
  ما هو · كيف يفكّر · ماذا يعرف · ماذا لا يعرف · نسبة الاكتمال · قائمة ما قبل البيتا.
- **توسيع التغطية**: ١١ عطلًا + ~٣٤ عرَضًا جديدًا → تغطية المهن ٣٨٪ → **٩٠٪** (١٩/٢١).
- **مركز القيادة**: العقل · خريطة النظام · التفسير (`describe()`) · العقل الحيّ · التعلّم.
- **الذاكرة المطبَّقة (المرحلة ب)**: المعرفة المعتمَدة بشريًّا تُقرأ وتُطبَّق في `understand()`
  (Observe→Suggest→Approve→**Apply**، القانون #3).
- **تنظيف**: حذف كود ميّت (TikTokFeed، بقايا SQLite).

## الانضباط الهندسيّ
- **اختبارات دائمة**: `npm test` = ٤١ اختبارًا (١٣ للعقل + ٢٨ للخادم)، وCI يمنع الدمج عند الفشل.
- **الدستور**: ADR-0001 (المعرفة) · ADR-0002 (المعمار) · ADR-0003 (كلّ شيء قابل للتفسير).
- **خطّة البيتا**: `docs/BETA_SPRINT.md` — النطاق، الأرقام، والحلقة اليوميّة.
