# DR-0004: حلقة التعلّم كفلسفة موحّدة (Learning Loop) + قانون اختبار المعرفة

- **التاريخ:** 2026-07-10
- **الحالة:** معتمَد
- **يمسّ:** الدستور (قانون ١١ جديد) · المعمار (Event backbone) · الخصوصية

## السياق
توجيه صريح بتحويل العقلية: AMANZINE ليس «محرّك بحث يتحسّن»، بل **نظام يتعلّم من كل تفاعل**. المطلوب أن يصبح كل تفاعل (بحث/نقر/تصفّح/اتصال/حجز/شراء/تقييم/عودة) مصدر معرفة يحسّن القرار القادم — و**Learning Loop كفلسفة لا كـEngine جديد**.

## القرار
1. **قانون دستوري جديد (١١) — اختبار المعرفة:** قبل أي Route/Table/Engine/Component، يجب أن يجيب: ما المعرفة التي يولّدها؟ كيف يحسّن القرار القادم؟ وإلا فليس أولوية.
2. **وثيقة `08_LEARNING_LOOP.md`:** تعرّف القمع، عقد الحدث→المرحلة، درجة التعلّم (Learning Score)، ولوحة «عقل AMANZINE».
3. **التنفيذ بالتطوّر فوق Event Bus (القانون ٤):** مشترك واحد `learning.js` (من عائلة `analytics`/`rules`) يحوّل أحداث القمع الموجودة إلى تجميع يومي **مجهّل** (`learning_daily`). **لا محرّك تعلّم أحادي (monolith).**
4. **مقياس أوسع:** من «عدد نتائج البحث» إلى **Learning Score** عبر القمع (searchSuccess/view/contact/booking/order/review). تُعرَض عبر `GET /api/knowledge/brain` (أدمن، مجهّل).

## البدائل المرفوضة
- **Learning Engine أحادي بجداول متعددة:** مرفوض — يخالف القانونين ٤ و٨ ويكرّر Event Bus. المستخدم نفسه طلبها «فلسفة لا Engine».
- **قياس عبر تتبّع مربوط بالمستخدم:** مرفوض الآن — PII (انظر الخصوصية).
- **بناء لوحة Brain كاملة فورًا:** مرفوض — لوحة بلا بيانات؛ تُبنى بعد امتلاء الإشارات.

## الأثر
- **العقود:** إضافة غير كاسرة. المشترك سلبيّ (يستهلك أحداثًا موجودة) وصامت الفشل.
- **الخصوصية:** `learning_daily` عدّادات يومية **بلا `userId`**. القصّة الكاملة للمستخدم (`intent_history`) تبقى موقوفة على بوابة `DR-0003` §7.
- **العقلية:** كل إضافة لاحقة تُقاس بقانون ١١، لا بعدد الملفّات.
- **المسموح بعده:** ربط بقيّة أحداث القمع في المسارات؛ إضافة مقاييس Brain (فئات/مدن/confidence) تدريجيًا؛ ثم واجهة اللوحة.

## المتابعة
- هذا الـDR ينفّذ: `learning_daily` + `learning.js` (subscriber + `brain()`) + `/api/knowledge/brain`.
- التالي المقترح: (c من DR-0003) تغذية راجعة صريحة 👍/👎 على النتائج — إشارة مجهّلة تُثري القمع وتغذّي `search_misses` عند «لا».
