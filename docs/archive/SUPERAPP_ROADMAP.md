# AMANZINE — خارطة طريق الـ Super App المغربي

> تحويل AMANZINE من "متجر لكل تاجر" إلى **منصة مغربية شاملة** تجمع المتاجر
> والمنتجات والخدمات والسوق المحلي والتوصيل والتواصل في تطبيق واحد.
> هذه الوثيقة تربط كل فكرة برؤية Allo Servix بعمل ملموس فوق معمارية AMANZINE الحالية.

---

## 0. نقطة الانطلاق (ما هو موجود فعلاً اليوم)

| المكوّن | الحالة |
|---|---|
| تعدّد المستأجرين (كل حساب = متجر) | ✅ `users` + عزل بـ `user_id` في كل جدول |
| منتجات/طلبات/زبائن/كوبونات/ولاء/توصيل/تحليلات | ✅ كاملة |
| واجهة المتجر العامة `/store/:userId` | ✅ |
| WhatsApp + AI + بثّ + وسائط | ✅ |
| **مقدّمو خدمات + حجوزات + توفّر (alloservix)** | ✅ أُنجزت هذه الجلسة (backend + صفحة تاجر) |
| مصادقة مؤمَّنة (كوكيز HttpOnly) + إخفاء الأسرار | ✅ أُنجزت هذه الجلسة |
| حقول GPS (`latitude/longitude/city`) على المقدّمين | ✅ جاهزة في جدول `providers` |

## ⚠️ التنبيه المعماري الأهم (يحكم كل ما يلي)

AMANZINE اليوم **معزول بين المتاجر** (كل قراءة مقيَّدة بـ `user_id` — وهذا ما حصّنّاه أمنيًا للتوّ).
الـ Super App يتطلّب **طبقة عامة تقرأ عبر كل المتاجر** (اكتشاف حسب المدينة، خريطة، بحث موحّد).

القاعدة الذهبية: الطبقة العامة تكشف **فقط** ما وُسم صراحةً بأنه عام ومعتمَد
(`status='published'` للمنتجات، `status='approved'` للمقدّمين/المتاجر)، ولا تكشف أبدًا
بيانات الزبائن أو الطلبات أو الأسرار. أي endpoint جامع = مجهَّل + للقراءة العامة فقط + محدود المعدّل.
هذا يحافظ على المكاسب الأمنية بينما يفتح المنصّة.

## المراحل (مرتّبة حسب الأثر/الاعتماد)

### 🟢 Phase 1 — نواة الاكتشاف المحلي (العمود الفقري للـ Super App)
*هذه المرحلة وحدها هي ما يحوّل "مجموعة ميزات" إلى "Super App".*

- **بيانات:** جدول `merchant_profiles` (ملف عام للمتجر: شعار، مدينة، GPS، وصف، حالة اعتماد)؛
  إضافة `city` + `is_public` للمنتجات.
- **backend عام (مجهَّل):**
  - `GET /api/discover/products?city=&q=&category=&max=` — منتجات معتمدة قرب المدينة عبر كل المتاجر
  - `GET /api/discover/services?city=` — مقدّمو خدمات معتمدون (يعيد استخدام `providers/public`)
  - `GET /api/discover/merchants?city=` — متاجر معتمدة
- **واجهة:** مُنتقي مدينة (الدار البيضاء/الرباط/طنجة/مراكش/أكادير…) + صفحة رئيسية للمستهلك
  (`Produits proches / Services proches / Commerçants proches / Offres proches`).
- **مخرج:** أول تجربة "Super App" حقيقية.

### 🟢 Phase 2 — الصفحات الاحترافية + الطلبات الفورية
- **صفحة مقدّم/متجر غنية** ("كل شيء مرتبط"): صور/فيديو، خبرة، لغات، تقييم، أعمال سابقة،
  أوقات عمل، أزرار WhatsApp/اتصال/طلب خدمة — مع تنقّل داخلي بين الأقسام.
- **طلب خدمة (Service Request Broadcast):** "أحتاج كهربائي" → نموذج (نوع/مدينة/حي/صورة/فيديو/وصف/ميزانية/تاريخ)
  → إشعار كل المقدّمين المطابقين في تلك المدينة/التصنيف. جدول `service_requests` + `request_offers`.
- **تصنيفات الخدمات** الاحترافية (Électricien/Plombier/Peintre/Climatisation/…).

### 🟡 Phase 3 — البحث الذكي + الخريطة
- بحث موحّد بفلاتر: النوع/المدينة/السعر/المسافة/"متاح اليوم".
- خريطة تفاعلية (Leaflet + OpenStreetMap — بلا مفتاح مدفوع) تعرض المتاجر/الخدمات/العروض/المستخدم.
- ترتيب حسب المسافة (Haversine على `lat/lng` الموجودة).

### 🟡 Phase 4 — إثراء الـ Marketplace
- **طلب منتج غير موجود** ("Je recherche ce produit") → بثّ للتجار.
- **المستعمل (Occasion)** + **العروض اليومية / Flash Sale** (قسم موحّد يعيد استخدام الكوبونات).
- **المفضلة الموحّدة** + **سجل طلبات موحّد** (منتجات + خدمات + توصيل في صفحة واحدة).

### 🟠 Phase 5 — الدفع + التوصيل الحي + مساعد AI
- **الدفع:** CMI (بطاقة مغربية) + COD الموجود + محافظ — عبر الخادم (لا أسرار في العميل، على نمط H-1).
- **تتبّع توصيل حيّ** (يبني على WebSocket الموجود + مزوّدي التوصيل).
- **مساعد AI للمستهلك:** "جد لي سبّاكًا اليوم" / "حاسوب بـ 7000 درهم" → يستعلم طبقة الاكتشاف ويجيب
  (يعيد استخدام `ai.js` + حصص H-5).

### 🟠 Phase 6 — عموديات متقدّمة
- المزادات (Enchères) · الحجوزات القطاعية (مطعم/طبيب/صالون/فندق/مدرّب) على أساس محرّك الحجز الموجود ·
  مجتمع (أسئلة/أجوبة) · اشتراكات ومتابعون للمتاجر.

## المبادئ الحاكمة
1. **إضافي لا كاسر:** كل مرحلة جداول/مسارات/صفحات جديدة — لا نكسر تدفّقات التاجر الحالية.
2. **الأمان أولاً:** الطبقة العامة تكشف المعتمَد/المنشور فقط، مجهَّلة، محدودة المعدّل.
3. **إعادة الاستخدام:** WhatsApp/AI/الكوبونات/التوصيل/WebSocket موجودة — نبني فوقها لا بجانبها.
4. **مغربي أولاً:** مدن المغرب، الدارجة/الفرنسية، CMI، COD.
