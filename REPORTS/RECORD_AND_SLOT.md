## ① `record()` — البابُ الوحيد

`setTurns` كان يُنادى من مواضعَ متفرّقةٍ في ملفٍّ من ألفِ سطر، فكلُّ مسارٍ
جديدٍ عليه أن **يتذكّر** أن يكتب. ونسي مساران — كلاهما مقيسٌ في المتصفّح.

```ts
const record = (...entries: Turn[]) => {
  const clean = entries.filter(e => e && typeof e.text === 'string' && e.text.trim());
  if (!clean.length) return;
  setTurns(t => [...t, ...clean]);
};
```

أربعةُ مسارات تمرّ منه: الجملة · ملءُ الفراغ · جوابُ الاستيضاح · **التصحيح**.
و«من جديد» وحدَه يصفّر. **ليس محرّكًا ولا طبقة** — منعُ تكرارِ صنفٍ من الخطأ
وقع مرّتَين، بنفس شكلِ «عقدُ بحثٍ واحد» و«مطابِقٌ واحد».

## ② `fillSlot` — أخطرُ ما وجدناه، وسببُه أُثبت بالتسجيل لا بالفرض

**العَرَض**: «بدّل الثمن ديال هاد المنتوج» ⇒ تظهر خانةُ «بشحال؟» ⇒ يكتب
الإنسانُ **179** ⇒ **لا يتبدّل الثمنُ ولا تُقال رسالةُ فشل.**

**التشخيصُ بتسجيلٍ مؤقَّتٍ في المتصفّح** (أُزيل بعده):

```
[TRACE fillSlot] prev=true live=true subject=true slot=price value=179
[TRACE verdict]  ask | trace: ["الإشارة «this» ⇒ «كسوة ديال الدراري»",
                               "ينقص من الفعل: بشحال؟"] | amount=179
[TRACE fillSlot] EXIT-2 dec.mode=clarify
```

**بعد الملء `amount = 179`، والحَكَمُ ما زال يقول «ينقص: بشحال؟».**

**السبب**: النقصُ مُعلَنٌ في **قائمتَين**:

| القائمة | الشكل | تحترم `u.amount`؟ |
|---|---|---|
| `unmetNeeds(match, { price: said })` | مفاتيحُ مصنَّفة | ✅ نعم |
| `u.action.needs` | **نصٌّ حرّ** `['بشحال؟']` | ❌ **لا** |

وهذا العطبُ **موصوفٌ حرفيًّا منذ زمنٍ في `liveSentence.ts:119`** («والنقصُ
مُعلَنٌ في قائمتَين لا واحدة… وإصلاحُ القائمتَين في مكانهما عملٌ آخرُ أُبلغ
به») — وُصف ولم يُصلَح، فبقي يُسقِط المسار.

**أقلُّ إصلاحٍ مُثبَت** — لا قائمةَ ثالثة، ولا إعادةَ تصميم:

```ts
function amountAnswers(need: string, u: Understanding): boolean {
  return u.amount != null && /شحال|ثمن|كمي|عدد|بكم/.test(need);
}
```
تُطرَح في **الفرعَين** اللذين يقرآن القائمةَ الحرّة — بنفس شكل الطرح القائم
فوقها سطرًا (`!(pointed && /منتج|منتوج/.test(n))`): كما تُطرَح حاجةُ «أيّ
منتج؟» حين حلّتها الإشارة، تُطرَح «بشحال؟» حين حلّها رقمٌ مقروء.

## ③ `fixNow` — التصحيحُ يدخل السياق، ولا يُنفَّذ به شيء

```ts
if (wrong.field !== 'all' && fixText.trim()) {
  record({ who: 'user', text: fixText.trim() }, { who: 'sys', text: thanks });
}
```

**ولا `submit` ولا `applyVerdict` ولا `setPage`** — يحرسها الاختبار.
الذاكرةُ تعين على الفهم وليست إذنًا: من صحّح لم يطلب تنفيذًا جديدًا.
و«كلشي غالط» لا يُسجَّل — لا نصَّ فيه، وتسجيلُه كلامًا للإنسان يلوّث السياق.

## ⑥ TRACE جديدٌ — سُجِّل ولم يُصلَح

**جملةُ الإنسان تُفهَم في صفحة الهبوط ثمّ تُرمى عند التسجيل.** مقيس:

```
/           «بغيت سبّاك فالرباط» ⇒ «فهمت هاكّا: 85% · 🔎 سبّاك · 📍 الرباط»
«ابدأ»   ⇒  /login          (صفحةُ حسابٍ كاملة)
تسجيل    ⇒  معالجُ إعدادٍ ملءَ الشاشة — **والرابطُ ما زال `/login`**
تخطّي    ⇒  /home           «شنو محتاج اليوم؟»
   الجملةُ محمولةٌ معه: **لا ❌**   ·   خانةُ الكتابة: **""**
```

**أربعُ شاشات، وسؤالٌ واحدٌ بصياغتَين** («شنو كتقلّب عليه اليوم؟» /
«شنو محتاج اليوم؟»)، والحاجةُ المفهومةُ تُرمى عند الحدّ.

وهو **نفسُ صنفِ G3**: الحالةُ تموت عند حدٍّ — هناك التنقّل، وهنا المصادقة.
مثالان الآن، لا واحد. **لا يُصلَح في هذه الجولة**؛ موضعُه قرارُ
Conversation Host.
